# Photos Directory

Place the celebrant's official photos in this folder:

1. **`hero-portrait.jpg` (or `.png` / `.webp`)**:
   - The primary formal centerpiece photo for the grand arch on the front page.
   - Recommended aspect ratio: 3:4 or 4:5 portrait (e.g., 1200 x 1600 px).
   - The current default points to `photos/hero-portrait.svg`. When ready, simply place your photo as `photos/hero-portrait.jpg` and update the `src` attribute in `index.html` (or keep the name `hero-portrait.jpg`).

2. **`journey-portrait.jpg`**:
   - A treasured childhood or growing-up photo for "The Journey to Fifteen" / "Desde Pequeña a Quinceañera" section.
   - Recommended aspect ratio: 4:5 or square (e.g., 800 x 1000 px).

3. **Additional Gallery Photos**:
   - Save high-res studio session or court of honor photos here for future subpages or extended galleries!
