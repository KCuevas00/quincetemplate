# Videos Directory

Place any video teasers, reels, or background video loops in this folder:

1. **`highlight-reel.mp4` / `background-loop.mp4`**:
   - Save your save-the-date teaser video or background video reel here.
   - Recommended format: H.264 MP4, 1080p, compressed for fast web loading.

2. **Audio Soundtrack**:
   - If you prefer to use a custom audio song instead of the built-in royal harp synthesizer, drop an MP3 file (e.g., `quince-waltz.mp3`) into this folder or `photos/`.
